=== dydownload 抖音 / B 站 下载工具 使用说明 ===

支持下载：
- 抖音无水印视频、图文/图集（图集自动归档为子文件夹，含实况图 + 背景音乐）
- B 站（bilibili.com）普通视频，支持多 P、画质选择、DASH 视频/音频分轨
- 暂不支持 B 站番剧（/bangumi/play/）

【给普通用户的简易方式】

1. 双击运行 dydownload.exe，出现窗口后服务自动启动

2. 在浏览器中登录抖音 (douyin.com) 和/或 B 站 (bilibili.com)

3. 安装浏览器扩展（给 Chrome/Edge 浏览器）：
   - 地址栏输入 chrome://extensions，打开「开发者模式」
   - 点击「加载已解压的扩展」，选择 extension/ 目录

4. 点击浏览器工具栏的 dydownload 插件图标，点「推送到 CLI」
   （之后每 5 分钟会自动推送；抖音、B 站分别写入不同的 Cookie 文件）

5. 下载（两种方式任选）：
   a) 浏览抖音视频/图集 或 B 站视频 → 点插件图标 → 地址已自动填好 → 点「下载无水印视频」
   b) 复制链接 → 粘贴到 dydownload.exe 窗口的输入框 → 选平台 → 点「下载」

6. 下载的文件保存在：downloads/
   抖音视频：downloads/<标题>-<id>.mp4
   抖音图集：downloads/<标题>-<id>/01.jpg、02.jpg …、xx_live.mp4 …、bgm.mp3
   B 站单 P：downloads/<标题>-<bvid>.mp4
   B 站多 P：downloads/<标题>-<bvid>_P01.mp4、_P02.mp4 …

【给开发者的命令行方式】

环境要求：conda 环境 dydownload (Python 3.10)

启动后端服务：
  python -m dydownload serve

下载抖音视频或图集（自动识别）：
  python -m dydownload download "https://v.douyin.com/xxxxx/"
  python -m dydownload download "https://www.douyin.com/note/xxxxx/"

下载 B 站普通视频（自动识别）：
  python -m dydownload download "https://www.bilibili.com/video/BV1xxxxxxxxxx"
  python -m dydownload download "https://b23.tv/xxxxx"

可选参数：
  --platform auto|douyin|bilibili   平台选择（默认自动）
  --quality 80|112|116|120         B 站画质（1080p / 1080p+ / 1080p60 / 4K）
  --parts all|first                多 P 处理（默认 all）
  --prefer-dash / --no-dash        默认 DASH 流
  --mux / --no-mux                 ffmpeg 自动合流（默认开启，需 ffmpeg）

查看 Cookie 状态：
  python -m dydownload status

测试 a_bogus 签名（仅抖音，同时显示图片列表）：
  python -m dydownload test "https://www.douyin.com/video/xxxxx"

重新打包 exe（修改源码后）：
  conda run -n dydownload pyinstaller dydownload.spec --distpath ./dist --workpath ./build --noconfirm

【ffmpeg 安装（用于 B 站 DASH 合流）】

任选其一：
  - 把 ffmpeg.exe 放到 ~/.dydownload/ffmpeg.exe
  - 把 ffmpeg 放进 PATH（system32 / 自定义目录）
  - 关闭合流：使用 --no-mux，会保留 .m4s 分轨文件

【常见问题】

Q: 下载提示 Cookie 过期？
A: 浏览器重新登录对应平台（抖音 douyin.com / B 站 bilibili.com），点插件图标推送 Cookie。
   也可以在 dydownload.exe 窗口的 Cookie 状态区看到当前 freshness。

Q: 下载提示作品不可用？
A: 作品可能已删除或设为私密。抖音换条链接；B 站确认 BV 正确且为普通视频（番剧暂不支持）。

Q: 插件显示「CLI 未启动」？
A: dydownload.exe 还没打开，或已关闭，重新双击运行即可。

Q: 文件保存在哪？
A: 默认在当前目录的 downloads/ 下；GUI 中可点「打开目录」直接跳转。
   抖音视频：<标题>-<id>.mp4
   抖音图集：<标题>-<id>/01.jpg 等
   B 站单 P：<标题>-<bvid>.mp4
   B 站多 P：<标题>-<bvid>_P01.mp4 等

Q: B 站画质只有 480p？
A: 1080p+ 需要有效 SESSDATA。重新登录 bilibili.com 并推送 Cookie。
