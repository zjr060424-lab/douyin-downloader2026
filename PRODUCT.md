# Product

## Register

product

## Users

Individuals downloading Douyin and Bilibili videos or image posts from a Windows desktop. They want to paste a link, confirm account readiness, choose a few media options, and see progress without navigating a complex interface.

## Product Purpose

Make local media downloads fast and legible while keeping cookie status, local service health, output location, and technical logs close at hand. Success means the primary download path is obvious and the user can diagnose a blocked task without leaving the window.

## Brand Personality

Energetic, competitive, and dependable. The interface should feel like a focused game launcher rather than a generic utility, while preserving the trust and predictability expected from a desktop tool.

## Anti-references

Default Tkinter widget stacks, generic card dashboards, neon cyberpunk overload, purple-blue gradients, decorative glass effects, and motion that continues when no task is active.

## Design Principles

1. Make the download action the single visual focal point.
2. Use strong hierarchy and directional shapes to create energy without hiding standard controls.
3. Keep service, cookie, and ffmpeg health visible before a task starts.
4. Animate only active task state and respect the operating system's reduced-motion preference.
5. Preserve readable text, keyboard focus, and high-DPI usability.

## Accessibility & Inclusion

Use text and shape in addition to color for status, maintain high contrast, support keyboard navigation, provide large control targets, scale correctly on Windows high-DPI displays, and disable nonessential animation when Windows client-area animations are disabled.
